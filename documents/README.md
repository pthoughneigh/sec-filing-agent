Documents
This folder contains SEC 10-K annual filings used by the stock research assistant.
How to download

OKLO
Go to https://oklo.com/investors/financials/sec-filings/default.aspx
Filter by Annual Filings 2026
Download the 10-K PDF and save it here as oklo.pdf

RocketLab (RKLB)
Go to https://www.annualreports.com/Company/rocket-lab-usa-inc
Download the 10-K PDF and save it here as rklb.pdf

IonQ (IONQ)
Go to https://investors.ionq.com/financials/sec-filings/default.aspx
Filter by Annual Filings 2026
Download the 10-K PDF and save it here as ionq.pdf
